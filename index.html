Sync with GitHub — works on any device

Stores your numbers in a private GitHub repository, so this tracker shows the same data on every device — computer, laptop or phone. You paste the token once, on this device only. Give it Contents: read & write on both repositories (the data one and the app one) and a long expiry — the app then publishes an encrypted copy of it automatically, and every other device signs in with just your password. The encrypted copy is publicly downloadable, so your password is what protects it; keep it long.

Data file — offline option

Keeps a real file on this computer that the tracker updates by itself every time you change anything — your numbers survive even if the browser ever clears its storage. Save it somewhere you won't delete, for example next to the app in the Expense-Tracker folder.

Backup & export

Your data is saved automatically in this browser as you type. For extra safety, set up the data file above (when available) and download a backup now and then — a backup file can bring everything back on this or any other computer, and is safe to copy to a USB stick or cloud drive.
